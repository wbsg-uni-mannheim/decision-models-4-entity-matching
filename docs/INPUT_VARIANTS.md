# Input variants of one record pair

The robustness experiments (Section "Robustness" of the paper) change only the text of the record pair; the prompt stays the selected prompt of each model and benchmark (F0). Below is the matching DBLP-ACM pair from the paper, `dblp_1944#acm_793`, in the default serialization and in every serialization and perturbation of the paper. The texts are generated by `inputs_study.state()` in `src/inputs_study.py` and are exactly what the models received as the state (decision models) or user message (Luna Gen.). Perturbations are seeded per pair, side, and variant (`inputs_study.rng()`), so other pairs get other deletions and typos. The perturbation `Lowercase values` (`R3_lowercase`) is missing here because it runs only on Dn7 Walmart-Amazon, WDC Products, billiger.de, and Semi-HETER; the other four benchmarks, DBLP-ACM among them, are lowercase already.

## Default serialization (F0)

```text
Record A:
authors: "luis gravano , surajit chaudhuri"
title: "evaluating top-k selection queries"
venue: "vldb"
year: 1999

Record B:
authors: "surajit chaudhuri , luis gravano"
title: "evaluating top-k selection queries"
venue: "very large data bases"
year: 1999
```
